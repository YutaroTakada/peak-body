# Peak Body

筋トレ、食事・栄養、体重を一括管理し、統合ダッシュボードで推移を確認するiOSアプリです。

## ドキュメント

- 要件定義: `docs/requirements/`
- エージェント間引き継ぎ: `docs/HANDOFF.md`
- マルチエージェント環境: `MULTI_AGENT.md`

## エージェントの起動

```bash
./scripts/agent.sh
./scripts/agent.sh requirements "既存要件をレビューして"
```

詳しい利用方法は [MULTI_AGENT.md](MULTI_AGENT.md) を参照してください。
