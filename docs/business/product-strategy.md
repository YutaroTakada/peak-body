# Peak Body プロダクト戦略ドキュメント（収益化 × UI/UX）

作成日: 2026-07-07
前提: MVP（筋トレ・食事・体重の手入力記録、端末内保存、統合ダッシュボード、日英対応、黒×ネオンのブランドテーマ、iOS 17+ / SwiftUI）

---

## 1. ビジョン

**「運動を継続すること自体が誇りになり、記録画面をSNSでシェアしてお互いを讃え合える世界」**

この戦略ドキュメントの全体構造は次の一本の因果でつながっている。

```
操作量の少ないUX → 記録が続く → 続いた記録は誇りになる → シェアされる
→ 讃え合いが生まれる → 新規ユーザー獲得（広告費ゼロ） → 収益化の母数が育つ
```

- **UXは継続率の装置**: 記録アプリの離脱理由の大半は「入力が面倒」。操作量削減はデザイン品質の話ではなく、LTV（サブスク解約率）に直結する収益戦略そのもの。
- **シェアカードは獲得の装置**: ユーザーが自発的に上げる記録画像が広告になる。黒×ネオンのビジュアルはシェア映えで競合（白基調のあすけん・カロミル等）と明確に差別化できる。
- **継続はLTVそのもの**: 「続けさせるアプリ」はサブスクの解約率が下がる。ビジョン＝収益モデルの強化装置。

## 2. UI/UX戦略 — 「記録は3タップ以内、確認は0タップ」

### 2.1 UX原則

1. **3タップ原則**: アプリ起動からどの記録も3タップ以内で保存完了できる。
2. **ゼロ入力を最優先**: 自動で取れるデータは入力させない（HealthKit・写真AI・前回コピー）。
3. **アプリを開かせない**: ウィジェット・Watch・通知から、起動なしで記録と確認を完結させる。
4. **入力のたびに小さく讃える**: 保存完了時のハプティクス＋ネオンのマイクロアニメーションで「今日もやった」を演出する。讃え合い文化はまずアプリがユーザーを讃えるところから始まる。
5. **エラーで入力を失わせない**（既存要件を継承）: 検証エラー時も入力値を保持する。

### 2.2 操作量を減らす具体機能

#### 筋トレ記録
- **「前回と同じ」ワンタップコピー**: 前回セッションの種目・重量・回数を丸ごと複製して微修正だけで保存。筋トレはルーティン性が高く、これだけで入力時間を8割削減できる。
- **ルーティンテンプレート**: 「胸の日」「脚の日」を登録し、ホームから1タップで開始。
- **セット入力の最適化**: 前セットの値を次セットに自動引き継ぎ。重量・回数はステッパー（±2.5kg / ±1回）で数値キーボードを開かせない。
- **Live Activities**: トレーニング中はロック画面に現在のセッションを常駐表示し、セット完了をロック画面から記録。

#### 食事記録
- **「よく食べるもの」履歴**: 直近・頻出の食事を上位表示し、タップだけで再登録。
- **食事プリセット**: 「いつもの朝食」を1タップ登録。
- **AI食事写真解析（Pro）**: 撮影→カロリー/PFC自動入力。入力コストが最も高い食事記録をゼロ入力に近づける。原価（1解析¥1〜3）はPro限定または回数制限で管理。

#### 体重記録
- **HealthKit自動取り込み**: スマート体重計 → ヘルスケア → Peak Body で**体重は完全ゼロ入力**にできる。手入力時も前回値をプリセットし±0.1kgステッパーで微調整のみ。

#### アクセス経路（アプリを開かせない）
- **ホーム/ロック画面ウィジェット**: 今日のストリーク・体重推移を常時表示（0タップ確認）＋記録画面へのディープリンク。
- **Apple Watch**: セット記録・体重確認を手元で完結。
- **App Intents / Siriショートカット**: 「体重 68.5」を音声だけで記録。
- **コンテキスト通知**: いつも記録している時間帯に未記録なら一言だけリマインド。「サボり指摘」ではなく「今日も来たね」のトーンで。

### 2.3 讃え合いを生むUX

- **保存完了の演出**: ハプティクス＋ネオングロウのアニメーション。記録という地味な行為に小さな達成感を毎回付与する。
- **ストリーク表示をホームの主役に**: 「連続◯日」を最も目立つ位置へ。途切れそうな日こそ優しく（週1回の「お休み券」等で完璧主義による離脱を防ぐ）。
- **シェアカードはワンタップ生成**: ワークアウト完了画面・マイルストーン達成時に、その場で黒×ネオンの1枚画像を生成 → Stories/X/TikTokへ即共有。「シェアしたくなる瞬間」に導線を置く（後からギャラリーを探させない）。
- **リスペクト機能（将来）**: 「いいね」ではなく「リスペクト」という語彙で、評価でなく敬意を送る文化をUIの言葉から作る。

### 2.4 UXのKPI

| 指標 | 目標 |
|---|---|
| 記録1件の保存完了までのタップ数 | 3タップ以内（中央値） |
| 記録1件の所要時間（中央値） | 筋トレ30秒 / 食事15秒 / 体重5秒 |
| 7日間で3日以上記録した利用者の割合 | 40%以上 |
| 30日ストリーク到達率 | 10%以上 |
| 記録に対するシェアカード生成率 | 5%以上 |

## 3. 収益化モデル（5案）

各目標利益はApple手数料15%（Small Business Program）控除・運用コスト差引後、広告費ゼロ・個人開発前提の現実ライン。

### 案A: フリーミアム・サブスク（本命）

記録・基本ダッシュボード・シェアは無料。Pro（月額¥600 / 年額¥4,800）で解放:
- 90日超の長期トレンド・相関ダッシュボード（食事×体重×トレ量）
- AI食事写真解析
- iCloud同期・Apple Watch・限定シェアカードデザイン

**UXとの接続**: Proの価値の柱は「分析」と「さらなる入力削減（AI解析）」。無料でも記録とシェアは全開放し、コミュニティの入口を狭めない。

| 時期 | 前提 | 月間利益目標 |
|---|---|---|
| 初月 | DL 1,500 / 課金転換2% = 30人 | **¥10,000** |
| 3ヶ月 | 累計DL 6,000 / 課金120人 | **¥55,000** |
| 6ヶ月 | MAU 8,000 / 課金250人 | **¥120,000** |
| 12ヶ月 | MAU 20,000 / 課金700人 | **¥350,000** |

### 案B: チャレンジイベント課金（ビジョン適合度が最も高い）

「30日スクワットチャレンジ」等の参加パス（¥300〜500/回）。完走者に限定バッジ・限定シェアカード。参加者同士が進捗をシェアしリスペクトを送り合う。課金が「自分への宣言」になり継続動機を強化する。

| 時期 | 前提 | 月間利益目標 |

### 案C: 法人向け健康経営プラン（B2B2C）

健康経営優良法人を目指す中小企業へ、社内チャレンジ＋管理レポートを¥200〜300/人/月で提供。運動率向上の社会的インパクトは最大だが、営業リソースが必要で立ち上がりは遅い。

プロテイン・フィットネスギア・ジムのアフィリエイトと、チャレンジへのブランド協賛（1本¥10〜30万）。押し付け広告にせず「頑張った人への特典」の形にして讃え合いの文化を守る。

## 4. 売り方（Go-to-Market）— シェアカードを成長エンジンに

1. **シェアカード最優先**: ワークアウト完了・体重マイルストーン・ストリークを黒×ネオンの1枚画像に自動生成 → ワンタップでStories/X/TikTokへ。画像に小さくアプリ名とQR。
2. **ハッシュタグ文化**: `#PeakBody` `#今日の積み上げ` で投稿を集約。公式アカウントが毎日ユーザー投稿をリポストする「讃える運営」。
3. **縦型動画マーケ**: 「記録が続かない人が90日続いた」系のBefore/After動画。フィットネス系マイクロインフルエンサー（1〜5万フォロワー）に無料Pro付与で先行体験。
4. **ASO**: 「筋トレ 記録」「体重 管理」「食事 記録」で日本語最適化。ダーク×ネオンのスクリーンショットで差別化。スクショの1枚目は機能一覧でなく「3タップで記録完了」の体験訴求にする。
5. **App Storeフィーチャー狙い**: 正月・夏前（5〜6月）のフィットネス特集に合わせてAppleへピッチ。UXの磨き込み（Live Activities・ウィジェット・Watch対応）はフィーチャー選定でも強く効く。
6. **コミュニティ**: Discord/LINEオープンチャットで初期100人のコアユーザーを直接運営し、チャレンジのテスト場にする。

| P0 | 「前回と同じ」コピー・ルーティンテンプレート・頻出食事履歴 | UX | 3タップ原則の実現。入力時間8割削減 |

### 実行シーケンス

1. **〜1ヶ月**: MVPリリース + P0一式（シェアカード・ストリーク・前回コピー・HealthKit体重）。無料で配りSNS獲得ループと「3タップ原則」を検証。
2. **2〜3ヶ月**: Proサブスク導入（iCloud同期・Watch・ウィジェットを課金価値に）。初回チャレンジはDiscordで手動運営してテスト。
3. **4〜6ヶ月**: アカウント基盤＋バックエンドを構築し、リスペクト機能とチャレンジをアプリ内実装。AI食事解析リリース。協賛営業開始。
4. **7〜12ヶ月**: 法人プラン営業、トレーナーマーケットプレイス設計着手。

## 6. 前提と注意

- 数字は広告費ゼロ・個人開発前提の現実ライン。SNSバイラルが当たれば上振れ、初月はApp Store審査時期でぶれる。
- Apple手数料はSmall Business Program（15%）適用前提。
- 現MVPは端末内保存・アカウントレスのため、リスペクト機能・チャレンジ・法人プランには**アカウント基盤とバックエンドが必要**。これが最大の技術投資判断ポイント。
- AI食事写真解析はAPI原価（1解析¥1〜3程度）がかかるため、Pro限定または回数制限で原価をコントロールする。
- ウィジェット・Watch・Live Activities・App Intentsは実装コストが分散しやすい。まず**ホーム画面ウィジェット＋前回コピー**の2つに絞って「操作量が減った」体感を作ってから広げる。
